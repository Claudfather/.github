# Contributing to Claudfather

Thanks for helping. These defaults apply to Claudfather's own repositories that have no `CONTRIBUTING.md` of their own. Where a repository has one, such as [clauDNA](https://github.com/Claudfather/clauDNA/blob/main/CONTRIBUTING.md), follow that instead. Forks of third-party projects follow their upstream's rules.

## Find the project that owns the change

| Change | Repository |
| --- | --- |
| Fleet composition, setup, permissions, supervision, Plane | [Claudlobby](https://github.com/Claudfather/Claudlobby) |
| Skills, agents, hooks, engineering workflows | [clauDNA](https://github.com/Claudfather/clauDNA) |
| Knowledge vaults and the `claudron` CLI | [Claudron](https://github.com/Claudfather/Claudron) |
| The organization profile, mission, brand reference, and these defaults | [.github](https://github.com/Claudfather/.github) |

The [mission](https://github.com/Claudfather/.github/blob/main/PROJECT_MISSION.md#responsibilities) explains these boundaries. Security problems go through the [security policy](https://github.com/Claudfather/.github/blob/main/SECURITY.md), never a public issue.

## Report a bug

Open an issue in the owning repository with the version or commit, your host OS, the steps to reproduce, what you expected, and what happened. Remove tokens, chat IDs, and private vault content from anything you share.

## Propose a change

For anything larger than a small fix, open an issue first so the approach can be agreed before you build it.

Keep each pull request to one purpose. In its description, say what changed, why, and how you verified it. Fill in the repository's pull request template where it has one. Run the checks the repository documents (its README, `Makefile`, or CI workflows) and include the evidence. A claim that something works should say exactly what you ran and what you saw.

## Documentation

Describe what works today and link to the owning guide rather than copying commands between repositories. Public wording about product names, destinations, and capabilities follows the [brand reference](https://github.com/Claudfather/.github/blob/main/BRAND.md#links-and-current-claims).
